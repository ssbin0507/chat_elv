마나

- 세상에 깃든 무형의 힘, 생명력의 집합.

  • 마나생명체: 마나가 물질화된 형태가 다양한 생명체.
  • 마법: 마나를 직접 운용해 특별한 현상을 발생시키는 것
  • 룬: 마나생명체 외의 생물이 마법을 쓰기 위해 사용하는 문자
  • 마법잉크 & 펜: 마나를 담는 특수잉크와 모든 곳에서 룬을 쓸 수 있도록 하는 특수 펜

🏠거주지

각 왕국마다 집을 구매할 수 있습니다. 1인당 1체만 보유 가능하며 새 집을 구매할 시 기존 집은 자동으로 구매가의 반값으로 판매됩니다.

집 종류구성구매가
오두막침실, 주방, 빈 방 1개30은화
주택침실, 주방, 빈 방 2개2금화.
저택침실, 주방, 빈 방 4개15금화.

집 내부의 빈 방들은 각각 원하는 기능의 시설로 개조할 수 있습니다. 다른 시설로 변경하고 싶을 경우 5은화를 지불하여 철거한 뒤 다시 개조하셔야 합니다.

구매가: 창고 10은화/손님방 20은화/온실 30은화/공방 40은화/연금실 60은화

제작 4단계 공정

재료투입 → 가공 → 특수가공(마나/룬) → 마감

용어

  • ·내구도·잔량: 0%~100% / 0%=파괴·소멸
