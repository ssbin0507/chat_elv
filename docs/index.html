본 도감책은 엘바테라 대륙의 탐험 규칙, d20 판정 체계, 마나 및 연금 연성, 직업군과 인물 기록을 담고 있는 고풍스러운 고서입니다.

Ⅰ. 개요 & 기본 규칙 Overview

내구도 & 잔량 시스템

범위: 0% ~ 100%

  • 내구도 보정: 26~50% (eb·DEF-1) / 1~25% (eb·DEF-2) / 0% (파손)
  • 내구 감소량: Ⅰ급(4~8%), Ⅱ급(3~6%), Ⅲ급(2~5%), Ⅳ급(1~4%), Ⅴ급(1~2%)
  • 잔량 소비자: 0% 달성 시 소멸·제거
  • 잔량 소비량: Ⅰ급(8~12%), Ⅱ급(6~9%), Ⅲ급(4~7%), Ⅳ급(2~5%), Ⅴ급(1~3%)

거주지 & 아이템 등급

거주지 종류: 없음 / 오두막 / 주택 / 저택 (구매 가능)

시설 개조: 빈방 1개당 시설 1개 (창고, 손님방, 온실, 공방, 연금실). 철거 시 빈방 복원.

아이템 등급: Ⅰ < Ⅱ < Ⅲ < Ⅳ < Ⅴ

장비 보정치(eb): Ⅰ(+1~2), Ⅱ(+3~4), Ⅲ(+5~6), Ⅳ(+7~8), Ⅴ(+9~10)

d20 판정 체계 및 산출 공식

구분 산출 공식 비고
일반 행동 판정 d20 + am + sb + eb ≥ dc 성공 불확실 행동만 판정
명중 판정 d20 + am + sb + eb ≥ Target DEF / AGI 방어 시 DEF / 회피 시 AGI 적용
피해량 산출 피해주사위 + am + sb + eb 단검(1d4), 장검(1d8), 파이어볼(8d6) 등

* DC: 매우쉬움(5) / 쉬움(10) / 보통(15) / 어려움(20) / 매우어려움(25) / 거의불가능(30)
* d20=1: 대실패(불리한 추가결과) / d20=20: 대성공(치명타 피해×2 및 추가이점)

기본 능력치 & am 보정 / sb 스킬 보너스

STR, AGI, CON, INT, MND, LUK, CHA (범위 1~20, 10~12가 일반인 평균)

수치12~34~56~78~910~1112~1314~1516~1718~1920
am-5-4-3-2-10+1+2+3+4+5

sb(스킬 보너스): Lv1(+1) / Lv2~3(+2) / Lv4~5(+3) / Lv6~7(+4) / Lv8~9(+5) / Lv10(+6)

Ⅱ. 세계관 & 4대 왕국 World & Kingdoms

대륙 종족 (Races)

15세 성인. 혼혈 가능하며 부모 특성 일부 계승.

  • 인간: 평균수명 100세 / 표준 균형형.
  • 엘프: 평균수명 1000세 / MND +2, STR -2 / 마나 우대.
  • 드워프: 평균수명 1000세 / STR +2, MND -2 / 힘 우대.
  • 수인: 평균수명 500세 / CON +2, LUK -2 / 동물 생태 특성.

지형 및 문화 환경

  • 사막: 고온건조 지대
  • 밀림: 고온다습 지대
  • 산맥: 저온평균 지대
  • 바다: 시원다습 지대
  • 평지: 온난평균 지대

* 귀족/왕족만 성(Surname)을 가지며 평민은 이름만 소유.

4대 주요 왕국 (Kingdoms)

아스테리아 인간

위치/수도: 동부 평지 / 루나렐

정체: 군주제 (여왕 발레리)

특징: 성벽 도시, 석조 건축, 개방적

실바니스 엘프

위치/수도: 서부 밀림 / 아르보르

정체: 군주+장로제 (여왕 티타니아)

특징: 트리하우스, 세계수 중심, 전통 중시

페르모스 드워프

위치/수도: 북부 사막 / 포르낙

정체: 대표+공화제 (대표 톨슨)

특징: 지하도시, 석굴 건축, 장인 정신

테리안 수인

위치/수도: 남부 산맥·바다 사이 / 페론

정체: 수장+선출제 (수장 오르반)

특징: 지형별 건축, 실력 존중

Ⅲ. 직업 시스템 Class System

유저는 주직업 1개와 부직업 1개를 자유롭게 선택/보유할 수 있습니다.

위치 (Witch)

역할: 마나도구 및 포션 제작 (남녀 구분 없음)

분류: 제작계 / 포션계 / 만능계 (C급 이상 전향)

등급: F(견습) ~ S(대마녀)

헌터 (Hunter)

역할: 사냥, 탐험, 생태계 탐색 및 관리

전투계: 검사, 궁수, 창사, 둔기사, 단검사, 격투가, 방패병, 마법사, 테이머

채집계: 탐험가, 생태학자

등급: 코퍼 < 실버 < 골드 < 플래티넘

요리사 (Chef)

역할: 전문 요리 및 미식 구율

등급: ⭐0(입문) ~ ⭐5 < 💫(마스터)

장인 (Artisan)

역할: 무기, 장신구, 의복 전문 제작

분류: 대장장이(무기·방어구), 세공사(보석·장신구), 직조공(천·자수)

등급: 견습 < 초급 < 숙련 < 전문 < 명장 < 거장

Ⅳ. 마나 & 제작 시스템 Mana & Crafting

마나 & 룬 (Mana & Runes)

  • 마나: 자연력과 생명력의 집합체
  • 마법잉크 & 펜: 마나를 담는 특수 잉크와 허공/지면에 서술하는 특수 펜
  • 룬(Rune): 마법 발동 문자 (주문 영창 없이 작성 시 즉시 발동, 예: ᚨᚱᛖ)
  • 마나생명체: 마나가 물질화된 생물 (위험도 하=일반 사육 가능)

제작 공정 (Crafting Process)

공정 단계: 재료투입 → 가공 → 특수가공 → 마감

  • 가공: 섞기, 분쇄, 절단, 가열, 냉각, 숙성, 압착, 직조, 망치질, 염색
  • 특수가공: 마나주입, 룬각인
  • 마감: 조율, 연마, 코팅, 플레이팅

* 동일 특성=강화 / 연관 특성=복합효과 / 상반 특성=약화·불안정

제작 결과 및 아이템 완성

등급확률: 등급확률합=100% / 성공률≤99% (실시간 반영)

완성품: d100≤성공률 시 성공, 성공 시 별도 d100으로 아이템 등급 결정. 재료의 원소·성향·특성 반영.
